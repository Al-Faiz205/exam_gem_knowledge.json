# Quantum Study Partner V2 - Term II Knowledge Base

This repository contains the core **Knowledge Engine** for the custom AI Gem: 'Quantum Study Partner V2'. 

## 🎯 Architecture Purpose
Designed exclusively for Tosif Alam (Class IX-B, Al-Faiz Model Academy) for the Term-II Final Examinations (2025-26). It acts as the ultimate **Single Source of Truth**, overriding standard AI training data with specific school syllabus blueprints and teacher mindset analytics.

## 📂 File Structure
* **`exam_gem_knowledge.json`**: The primary database containing:
  1. `student_profile`: Contextual anchoring for the AI.
  2. `syllabus_data`: Micro-level targeted topics, formulas, and V.V.I predictions for all 6 subjects.
  3. `examiner_prompt`: The strict God-Tier rules for evaluating and formatting exam answers.

## ⚙️ Deployment Instructions
1. Download `exam_gem_knowledge.json`.
2. Upload the file to the **Knowledge** section of the Gemini Custom Gem.
3. Ensure the AI's System Instructions strictly reference `syllabus_data` and `examiner_prompt`.
